# Housing Price Analysis Dashboard | Power BI Project

A professional Business Intelligence project built using Microsoft Power BI, DAX, and Excel-based data modeling to analyze housing price trends and property market insights.

This project transforms raw housing data into an interactive analytics dashboard that provides insights into property prices, locations, market trends, property characteristics, and pricing factors.

---

## Project Overview

The objective of this project is to develop an end-to-end data analytics solution that demonstrates real-world Business Intelligence workflows.

The project includes:

- Data preparation and cleaning
- Data modeling
- DAX measure creation
- Interactive Power BI dashboard development
- Housing market analysis
- Business insight generation

The dashboard helps users understand pricing patterns, property distribution, and market behavior.
